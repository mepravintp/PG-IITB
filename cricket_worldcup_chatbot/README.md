# Cricket World Cup Chatbot

## Project Overview
A chatbot to answer queries and provide statistics about cricket world cups (ODI & T20, Men & Women) from 2020 onwards.

## Features
- Query matches, players, venues, and stats for world cups since 2020
- Supports both ODI and T20 formats, men and women
- Natural language query handling

## Folder Structure
- `data/raw`: Raw data files
- `data/processed`: Cleaned/processed data
- `src/chatbot`: Chatbot logic
- `src/nlp`: NLP modules
- `src/api`: API/backend code
- `src/utils`: Utility functions
- `notebooks`: Prototyping and EDA
- `tests`: Unit/integration tests
- `docs`: Documentation

## Sample Queries
- Who won the 2023 Men’s ODI World Cup?
- List top run scorers in the 2022 Women’s T20 World Cup.
- Where was the final of the 2021 Men’s T20 World Cup played?
- Show all matches played by India in the 2020 Women’s T20 World Cup.
- What was the highest team score in the 2022 Men’s T20 World Cup?
- Who took the most wickets in the 2023 Women’s ODI World Cup?

## Setup
1. Install dependencies from `requirements.txt`
2. Add data files to `data/raw`
3. Run ETL scripts to process data
4. Start chatbot backend
